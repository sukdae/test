# 학습용 데이터 모으기 (1단계)

앱 판정을 데이터로 보정하고 정확도를 숫자로 재기 위한 '정답이 붙은 데이터'를 모으는 방법입니다.
앱은 아직 스스로 학습하지 않습니다. 모은 데이터로 사람이 기준값을 다시 계산하고(2단계), 나중에 작은 모델을 시험합니다(3단계).

## 무엇이 저장되나

| 들어감 | 들어가지 않음 |
|---|---|
| 관절점 33개 좌표(화면 크기 대비 0–1 숫자)와 신뢰도 | 영상, 사진 |
| 각도·리듬·펴짐 지표, 앱 판정 | 이름, 얼굴, 연락처 |
| 평가자 판정(회차별 실수 체크), 메모 | 평가자 이름 (무작위 id와 역할만: 트레이너/체대생 등) |
| 입력한 몸무게·바벨 무게·1RM | 위치·기기 정보 |

- 모든 데이터는 먼저 **그 기기 안에만** 저장됩니다. 설정의 '학습용 데이터 내보내기'로 직접 파일을 만들어 보낼 때만 밖으로 나갑니다.
- **찍힌 사람에게 동의를 받은 영상만** 학습용 데이터가 됩니다. 결과 화면에서 동의 체크를 하지 않으면 판정만 남고 관절점은 저장되지 않습니다.
- 관절점 좌표도 움직임 특징으로 사람을 알아볼 여지가 있어, 연구·보정 목적으로만 쓰고 공개 저장소(깃허브 등)에 올리지 않습니다.
- 본격적으로 모으기 전(서버 수집, 학교 수업·연구로 쓰기 전)에는 학교 연구윤리 담당이나 전문가에게 개인정보 처리 방식을 확인하세요.

## 현장 설문 (촬영 없음) — 기본 방법

운동하는 사람에게 직접 폰을 건네 받는 설문이에요. **촬영하지 않고**, 참여자가 뼈대 인형을 막대로 움직여 "어디부터 지적할지"를 직접 정해요. 한 명에 약 30초, 문항 4개.

1. 홈 맨 아래 **'현장 설문 (촬영 없음)'**.
2. 참여자에게 첫 화면 문구를 보여 주고 동의를 받음 → 성별·나이·경력(선택) → **'동의하고 시작'**.
3. 문항마다 막대를 움직여 인형 자세를 바꾸고, 지적할 지점에서 **'여기부터예요'**(모르면 '잘 모르겠어요').
   1. 스쿼트 깊이 — 허벅지가 수평보다 몇 도 덜 앉으면 '얕다'?
   2. 뒤꿈치 들림 — 뒤꿈치가 몇 cm 뜨면 '들렸다'? (발 확대 그림)
   3. 데드리프트 마무리 — 엉덩이를 어디까지 펴야 '끝까지 폈다'?
   4. 데드리프트 뒤로 젖힘 — 몇 도부터 '젖혔다'?
   - 논문으로 이미 정해진 것은 묻지 않아요: 상체 숙임(잘못된 자세의 기준이 아님, Straub & Powers 2024), 무릎이 발끝 넘기(괜찮음, Fry 외 2003). 깊이도 '평행이 목표'는 논문이고, 몇 도부터 지적할지만 물어요.
4. '완료' 화면에서 **'다음 사람'** → 다음 참여자에게 폰 건네기.
5. 끝나면 설정(⚙) → **'설문 결과 내보내기 (엑셀 CSV)'**(한 사람 한 줄) / **'(분석용 JSON)'**.

- 저장되는 것: 문항별 값, 성별·나이대·경력(선택), 시간. 영상·관절점·이름은 없어요.
- 분석: `python3 tools/fit_thresholds.py formcheck-survey-*.json` → 문항별 중앙값·사분위·'앱보다 엄격하게 본 사람 비율'·경력별 중앙값. 중앙값이 앱 기준과 많이 다르면 기준값 조정을 검토해요.
- 참여자 생각과 '맞는 자세'는 다를 수 있어요. 이 설문은 '사람들이 어디부터 문제로 보는지'를 재는 것이고, 기준값은 논문·트레이너 의견과 함께 정해요.
- 테스트로 넣은 답은 설정(⚙) → **'설문 결과 초기화'**로 지우고 1번부터 다시 시작해요.

## 회차별 판정 (트레이너용, 더 정밀하게)

1. (설문 모드가 꺼져 있을 때) 영상을 분석한 뒤 결과 화면 '자세히 보기' → **회차별 판정 (학습용)**.
2. **동의 체크**: "영상 속 사람에게 학습용 사용 동의를 받았어요".
3. 회차를 고르고, 보이는 실수를 **모두** 체크 → '체크한 실수로 기록'. 실수가 없으면 '이 회차 문제 없음'.
   - 앱 판정을 보지 말고 영상만 보고 판정하는 것이 좋습니다(앱 판정에 끌려가지 않게).
   - 잘린 회차(*)는 분석에서 빠지니 판정하지 않아도 됩니다.
4. 모든 회차를 판정하면 '2/2회 판정'처럼 표시됩니다.
5. 설정(⚙) → 평가자 역할 선택 → **학습용 데이터 내보내기 (JSON)** → 파일 전달.

### 평가자 간 일치도
같은 영상을 **두 사람 이상이 따로** 판정하면, 사람끼리 얼마나 일치하는지(코헨 카파)를 잴 수 있습니다.
앱 정확도는 사람끼리의 일치도를 넘기 어렵기 때문에, 10–20개 영상은 두 명이 겹쳐 판정해 주세요.

## 얼마나 모아야 하나 (대략)

| 목표 | 필요한 양 |
|---|---|
| 기준값 보정(2단계) 시작 | 항목마다 '실수'로 판정된 회차 30개 이상, 전체 수백 회차 |
| 작은 학습 모델(3단계) 시험 | 수천 회차, 사람 수십 명 이상 |

- 같은 사람·같은 체육관만 많으면 그 사람에게만 맞춰집니다. 체형·성별·숙련도·촬영 각도를 다양하게 해 주세요.
- 일부러 틀린 자세 영상(얕게, 무릎 모으기 등)이 특히 부족합니다.

## 분석하기 (2단계 준비)

```bash
python3 tools/fit_thresholds.py formcheck-dataset-*.json
```

- 항목마다 지금 기준값의 일치율·정밀도·재현율, 데이터로 찾은 최적 기준값, 영상 단위 교차검증 결과를 표로 냅니다.
- 같은 영상의 회차가 학습·시험에 섞이지 않게 **영상 단위로** 나눠 검증합니다.
- 기준값을 바꿀 때는 `src/core/feedback.js` 등의 주석을 `[데이터: n회차, 날짜]`로 남기고, `tools/fit_thresholds.py` 의 `RULES` 도 같이 고칩니다.
