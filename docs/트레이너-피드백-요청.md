# 스쿼트 자세 분석 앱 — 피드백 부탁드립니다

폰으로 스쿼트 영상을 찍으면 관절 위치를 인식해서 자세 피드백을 주는 앱의 **시험 버전**입니다.
현장에서 회원을 지도하시는 입장에서 **앱이 하는 말이 맞는지** 봐 주시면 큰 도움이 됩니다.

- 링크: (GitHub Pages 주소)
- 폰 브라우저(크롬·사파리)로 열면 됩니다. 설치 필요 없음.
- 영상은 **폰 안에서만 처리**되고 서버로 보내지 않습니다.
- 의료 진단이 아니라 참고용 피드백입니다.

## 써 보는 방법 (10분)

1. **측면**: 옆 2~3m, 허리 높이, 머리부터 발끝까지 보이게. 맨몸 또는 가벼운 무게로 5회.
2. **정면**: 같은 세트를 앞에서. (첫 화면에서 '둘 다'를 고르면 측면 → 정면 순서로 받습니다)
3. 결과 화면 맨 위 **'이렇게 해 보세요'**(최대 3줄)와 영상 위 선·색 표시를 봐 주세요.
4. 가능하면 **일부러 틀린 자세**로도 한 번씩 찍어 주세요: 얕게 앉기 / 무릎 안으로 모으기 / 뒤꿈치 들기 / 몸을 한쪽으로 쏠리기.

## 여쭤보고 싶은 것

### 1. 지시 문구가 현장에서 쓰는 말과 맞나요?
앱이 실제로 내는 문장들입니다. 어색하거나 틀린 것에 표시해 주세요.

- [ ] 허벅지가 바닥과 평행해질 때까지 더 앉으세요
- [ ] 올라올 때 가슴과 엉덩이를 같이 올리세요
- [ ] 뒤꿈치로 바닥을 누르며 앉으세요
- [ ] 2.0초에 걸쳐 내려가세요
- [ ] 무릎을 발끝 방향으로 밀어 벌리세요
- [ ] 양발에 체중을 고르게 싣고 앉으세요
- [ ] 몸통을 가운데로 세운 채 앉으세요

### 2. 이 정도면 지적하시나요? (기준값)
논문에 수치가 없어 임시로 정한 값입니다. 너무 엄격/느슨하면 알려 주세요.

| 항목 | 지금 기준 | 적당 / 더 엄격하게 / 더 느슨하게 |
|---|---|---|
| 깊이 '얕음' | 허벅지가 수평보다 35° 넘게 위 | |
| 뒤꿈치 들림 | 다리 길이의 3% 넘게 들림 | |
| 무릎 안으로 모임 | 엉덩이–발목 선보다 다리 길이의 4% 넘게 안쪽 | |
| 상체 옆으로 기울어짐 | 5° 넘게 | |
| 엉덩이 한쪽 쏠림 | 스탠스 너비의 15% 넘게 | |
| 내려가는 속도 기준 | 2초 내려가기, 1초 올라오기 | |

### 3. 그 밖에
- 앱이 **잘못 잡은 것**(괜찮은데 지적함)이나 **놓친 것**이 있었나요?
- 회원들에게 자주 보이는 실수 중 **앱에 꼭 있었으면 하는 것**은?
- 결과 화면에서 **필요 없는 정보**나 **더 보고 싶은 정보**는?

## 영상을 보내 주실 수 있다면
틀린 자세 영상이 가장 부족합니다. 보내 주시면 기준값을 맞추는 데만 쓰고 앱에는 넣지 않습니다.
**본인 영상** 또는 **찍히는 분의 동의를 받은 영상**만 부탁드립니다.
