# 스쿼트 자세 분석 앱 — 피드백 부탁드립니다

폰으로 스쿼트 영상을 찍으면 관절 위치를 인식해서 자세 피드백을 주는 앱의 **시험 버전**입니다.
현장에서 회원을 지도하시는 입장에서 **앱이 하는 말이 맞는지** 봐 주시면 큰 도움이 됩니다.

- 링크: https://sukdae.github.io/test/
- 폰 브라우저(크롬·사파리)로 열면 됩니다. 설치 필요 없음.
- 영상은 **폰 안에서만 처리**되고 서버로 보내지 않습니다.
- 의료 진단이 아니라 참고용 피드백입니다.

## 써 보는 방법 (10분)

1. **측면**: 옆 2~3m, 허리 높이, 머리부터 발끝까지 보이게. 맨몸 또는 가벼운 무게로 5회.
2. **정면**: 같은 세트를 앞에서. (첫 화면에서 '둘 다'를 고르면 두 영상을 한 번에 올려도 측면·정면을 알아서 구분합니다)
3. 결과 화면 맨 위 **'이렇게 해 보세요'**(최대 3줄)와 영상 위 선·색 표시를 봐 주세요.
4. 가능하면 **일부러 틀린 자세**로도 한 번씩 찍어 주세요: 얕게 앉기 / 무릎 안으로 모으기 / 뒤꿈치 들기 / 몸을 한쪽으로 쏠리기.
5. **데드리프트(베타)**: 첫 화면에서 '데드리프트'를 고르고 측면·정면(또는 '둘 다')으로 5회. 컨벤셔널 기준이고, 기준 자세 일부만 논문 근거가 있어 특히 의견이 필요해요.
6. 결과 화면 '자세히 보기'의 피드백마다 **'맞아요 / 틀렸어요'**를 눌러 주시고, 앱이 놓친 실수는 **'앱이 놓친 실수 알려 주기'**로 남겨 주세요. 다 쓰신 뒤 설정(⚙)에서 평가자를 '트레이너'로 고르고 **'평가 기록 CSV 내보내기'** 파일을 보내 주시면 됩니다.
7. 결과 화면의 **'이미지로 공유'**로 결과를 받아 보세요. 회원에게 보낼 만한지 봐 주세요.

## 여쭤보고 싶은 것

### 1. 지시 문구가 현장에서 쓰는 말과 맞나요?
앱이 실제로 내는 문장들입니다. 어색하거나 틀린 것에 표시해 주세요.

- [ ] 허벅지가 바닥과 평행해질 때까지 더 앉으세요
- [ ] 올라올 때 가슴과 엉덩이를 같이 올리세요
- [ ] 뒤꿈치로 바닥을 누르며 앉으세요
- [ ] 2.0초에 걸쳐 내려가세요
- [ ] 무릎을 발끝 방향으로 밀어 벌리세요
- [ ] 양발에 체중을 고르게 싣고 앉으세요
- [ ] 몸통을 가운데로 세운 채 앉으세요
- [ ] (데드리프트) 마지막에 엉덩이를 앞으로 밀어 끝까지 펴세요
- [ ] (데드리프트) 끝에서 뒤로 젖히지 말고 곧게 서세요
- [ ] (데드리프트) 매 반복 바닥에서 잠깐 멈췄다 당기세요
- [ ] (데드리프트) 무릎보다 엉덩이를 뒤로 빼는 느낌으로 숙이세요

### 1-1. 몸 밖을 의식하게 하는 문구가 더 나을까요?
몸 밖의 대상(바닥, 바)을 의식하게 하는 '외부 초점' 문구가 움직임 효율에 유리하다는 연구가 있어요. 다만 무릎 위치 안내에서는 차이가 없었다는 연구도 있어요. 현장에서 어떤 쪽이 잘 통하는지 골라 주세요.

| 지금 문구 (몸 의식) | 대안 (바닥·바 의식) | 어느 쪽? |
|---|---|---|
| 무릎을 발끝 방향으로 밀어 벌리세요 | 바닥을 양발로 바깥쪽으로 밀어내세요 | |
| 올라올 때 가슴과 엉덩이를 같이 올리세요 | 올라올 때 바닥을 강하게 밀어내세요 | |
| 마지막에 엉덩이를 앞으로 밀어 끝까지 펴세요 | 마지막에 바를 몸에 붙인 채 끝까지 일어서세요 | |

### 2. 이 정도면 지적하시나요? (기준값)
논문에 수치가 없어 임시로 정한 값입니다. 너무 엄격/느슨하면 알려 주세요.

| 항목 | 지금 기준 | 적당 / 더 엄격하게 / 더 느슨하게 |
|---|---|---|
| 깊이 '얕음' | 허벅지가 수평보다 35° 넘게 위 | |
| 뒤꿈치 들림 | 다리 길이의 3% 넘게 들림 | |
| 무릎 안으로 모임 (참고, 2D 추정) | 엉덩이–발목 선보다 다리 길이의 4% 넘게 안쪽 | |
| 상체 옆으로 기울어짐 | 5° 넘게 | |
| 엉덩이 한쪽 쏠림 | 스탠스 너비의 15% 넘게 | |
| 내려가는 속도 기준 | 2초 내려가기, 1초 올라오기 | |
| 무게중심 앞뒤 쏠림 (참고, 추정) | 최저점에서 서 있을 때보다 발 길이의 25% 넘게 이동 | |
