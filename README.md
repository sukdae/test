# 폼 체크 — 스쿼트 자세 분석 (웹 프로토타입)

폰으로 스쿼트 영상을 찍거나 불러오면 관절 위치를 인식해서 자세 피드백을 주는 웹앱입니다.
**영상은 브라우저 안에서만 처리**되고 어떤 서버로도 보내지 않습니다. 설치하지 않아도 폰 브라우저로 열면 됩니다.

> 시험 버전입니다. 의료 진단이 아니라 참고용 피드백입니다.

## 할 수 있는 것

- **촬영 방향 선택**: 측면, 정면, 둘 다 중에서 고릅니다. '둘 다'에서는 영상 두 개를 한 번에 올리면 측면·정면을 자동으로 구분합니다.
- **이렇게 해 보세요**: 결과 맨 위에 고칠 점을 행동 문장으로 최대 3개 보여 줍니다. 잘한 점은 칩으로 표시합니다.
- **영상 위 표시**: 관절 선, 기준 자세 고스트, 쓰이는 근육, 발바닥 접지(뒤꿈치 들림), 등 라인을 그립니다.
- **측면 분석**:
  - 깊이(허벅지 수평 각도)
  - 상체·정강이 각도, 엉덩이가 먼저 올라오는지
  - 뒤꿈치 들림
  - 하강·상승 속도
  - 상체 흔들림, 등 곡률(실험)
- **정면 분석**:
  - 무릎이 안쪽으로 모이는지, 골반 기울기, 엉덩이 쏠림
  - 스탠스 너비, 상체 옆 기울기
  - 좌우 체중 분배(추정), 한쪽 발이 뜨는지
  - 좌우 근육 사용
- **정면 기준 자세**: 정면에도 논문 기반 기준 자세(중간 스탠스, 무릎이 안쪽으로 모이지 않음, 좌우 대칭)를 점선으로 겹쳐 보고 '나 vs 기준' 표로 비교합니다.
- **3D 합성 (둘 다 모드, 추정)**: 측면(앞뒤·높이)과 정면(좌우)을 반복 위상으로 맞춰 3D 대표 동작을 만들고, 돌려 볼 수 있는 뼈대와 진단표를 보여 주고, 문제가 있는 반복이 몇 회째인지 표시합니다. 무릎 방향 vs 발끝 방향, 3D 무릎 각도, 상체 기울기(앞·옆)를 다룹니다. 바 궤적(데드리프트는 손목, 스쿼트는 어깨 위치로 추정)과 앞뒤·좌우 흔들림 폭도 보여 주며, 판정 없이 정보로만 씁니다. 좌우·위아래로 끌거나 앞/옆/위 버튼으로 보는 방향을 바꿉니다. 두 영상이 같은 순간이 아니라서 근사값입니다.
- **두 영상 일치 확인**: 측면과 정면이 같은 세트가 아닌 것 같으면 경고합니다.
- **이미지로 공유**: '이렇게 해 보세요', 자세 장면, 3D 회차 표시를 이미지 한 장으로 만들어 카톡 등으로 보냅니다. 기본은 뼈대만 들어가고, '실제 영상 포함'을 켜야 영상 장면이 들어갑니다.
- **데드리프트 (베타)**: 측면·정면·3D를 스쿼트처럼 지원합니다. 기준 자세는 '무릎 → 엉덩이 → 함께 펴지는 3단계 순서'와 스티킹 포인트 각도(Kompf & Arandjelović 2017)를 따르고, 나머지 수치는 초깃값입니다. 정면에서 컨벤셔널/스모를 구분하고, 판정은 컨벤셔널 기준입니다.
- **친업·딥스 (베타, 측면, 어시스트 머신 포함)**: 팔꿈치·어깨(위팔)·상체 각도로 반복을 세고, 친업은 턱이 바 위로 올라가는지(입 vs 손 높이)·매달림에서 팔을 다 펴는지·몸 반동을, 딥스는 깊이·위에서 팔을 다 펴는지·어깨가 많이 젖혀지는지를 봅니다. 손이 바·손잡이에 고정되므로 기준 자세는 손목에서부터 그립니다. 딥스 기준 자세는 바 딥 실험 평균(McKenzie 외 2022), 친업은 팔꿈치 움직임 범위(Youdas 외 2010)와 엉덩이·무릎을 살짝 굽혀 고정하는 자세(Garavaglia 외 2024)가 논문 근거이고 어깨·상체 각도는 초깃값입니다. 친업은 엉덩이를 많이 굽히는지, 반복할수록 다리 흔들림이 커지는지도 참고로 알려 줍니다. 두 번째 무게 칸은 '보조 무게'가 되어 '실제로 드는 무게 = 몸무게 − 보조'를 보여 줍니다.
- **스쿼트 리듬**: 내려가기 2–4초 · 올라오기 약 1초를 기준으로 안내합니다(Wilk 외 2021, Kojic 외 2024, Morrissey 외 1998, Gepfert 외 2021). 한 반복 0.5–8초면 근비대 효과가 비슷하다는 메타분석(Schoenfeld 외 2015)이 있어, 범위 밖은 '틀림'이 아니라 안내로만 보여 줍니다. 3D는 내 실제 리듬으로 재생되고 기준 자세는 기준 리듬(3초 내려가기·1초 올라오기)으로 같이 움직이며, CSV 내보내기에는 반복별 내려가기·바닥 멈춤·올라오기 시간과 기준 범위 판정이 들어갑니다.
- **펴짐(신전)**: 올라올 때 무릎·엉덩이가 펴지는 순서(스쿼트 = 함께, 데드리프트 = 무릎 먼저; Hales 2026)와 각속도, 마무리 각도, 마무리에서 상체가 뒤로 넘어간 정도·등 젖힘(실험)을 계산해 CSV와 3D 진단표·막대로 보여 줍니다. 허리 과신전은 수치 기준을 준 연구가 없어 판정 없이 수치만 보여 줍니다.
- **무게·개인 리듬**: 1RM(선택)을 넣으면 강도(%1RM)를 계산해, 무거운 스쿼트 세트는 올라오기 기준을 스쿼트 무게–속도 표(Rendeiro-Pinho 외 2026)에 맞춰 늘립니다. 세트 안 속도 손실(첫 반복 대비)과, 저장한 기록 중 같은 무게의 '평소 나' 리듬과의 비교도 보여 줍니다.
- **현장 설문 (촬영 없음)**: 참여자가 뼈대 인형 각도를 막대로 움직여 '어디부터 지적할지'(스쿼트 깊이·뒤꿈치 들림, 데드리프트 마무리·젖힘 — 논문에 수치가 없는 항목만)를 직접 정합니다. 한 명 30초, 영상·이름 없음. 엑셀 CSV·분석용 JSON으로 내보내 `tools/fit_thresholds.py`로 앱 기준값과 비교합니다.
- **학습용 데이터 모으기 (1단계)**: 결과 화면 '회차별 판정 (학습용)'에서 회차마다 실수를 체크하고, 찍힌 사람의 동의를 확인하면 관절점 숫자·지표·앱 판정·사람 판정이 기기에 쌓입니다(영상·이름 없음). 설정에서 JSON으로 내보내고 `tools/fit_thresholds.py`로 기준값 일치율·최적값·평가자 간 일치도를 계산합니다. 방법은 `docs/데이터-수집-가이드.md`.
- **견갑 고정(어깨 으쓱)은 판정하지 않습니다**: 같은 관절점 모델에서 가장 부정확한 항목이라는 검증 연구(Pavlikov 외 2026)가 있고, 실제 영상에서도 상체 기울기·머리 움직임과 구분되지 않았습니다. '앱이 놓친 실수'로 기록을 모읍니다.
- **무게중심 앞뒤 이동 (스쿼트, 추정)**: 측면 영상에서 머리·몸통·팔·다리 위치를 대략적인 몸무게 비율로 평균 내 무게중심을 추정하고, 앉을수록 서 있을 때보다 발 길이의 30% 넘게 앞뒤로 쏠리면 참고로 알려 줍니다. 영상 위 발 아래에 삼각형으로 표시합니다. 발 앞·뒤 체중 분배가 관절 부하를 바꾼다는 연구(Biscarini 외 2013, Chen 외 2025)에 근거하지만, 비율과 30% 기준은 초깃값입니다. 데드리프트는 바벨 무게를 입력했을 때만 씁니다.
- **판정 평가 (맞아요 / 틀렸어요)**: '자세히 보기'의 피드백 항목마다 맞아요·틀렸어요 버튼이 있고, '앱이 놓친 실수 알려 주기'로 빠진 실수를 회차와 함께 남길 수 있습니다. 기록은 기기에만 저장되고, 설정에서 평가자(트레이너/체대생 등)를 고른 뒤 CSV로 내보내 기준값 보정에 씁니다. 영상과 이름은 들어가지 않습니다.
- **무게 입력 (선택)**: 홈에서 몸무게와 바벨 무게를 넣으면 바벨을 점 질량으로 더한 '몸 + 바벨' 무게중심을 계산합니다(바벨 위치: 스쿼트는 어깨, 데드리프트는 손목으로 근사). 데드리프트 무게중심 판정은 바벨 무게를 넣었을 때만 켜집니다. 몸무게는 기억하고 바벨 무게는 종목별 마지막 값을 기억하며, 기기 밖으로 보내지 않습니다. 설정의 '모든 기록·무게 삭제'로 지울 수 있습니다.
- **심상 연습 안내**: 결과 화면에서 기준 자세를 기준 리듬으로 재생해 '보며 머릿속으로 따라 하기'를 안내합니다. 심상 연습은 실제 운동보다 효과가 작지만 근력 유지·향상에 도움이 된다는 메타분석이 있습니다(Paravlic 외 2018).
- **기록**: 세트별 결과를 기기 안(IndexedDB)에 저장하고 추이 그래프로 보여 줍니다. 영상 저장은 기본으로 꺼져 있습니다.

## 기준 자세와 근거

비교 기준은 특정 사람의 영상이 아니라 **논문을 근거로 만든 기준 자세**입니다.

- 깊이: 허벅지가 바닥과 평행 (Escamilla 2001)
- 상체와 정강이 기울기가 비슷하게 (Straub & Powers 2024)
- 천천히 내려가고 빠르게 올라오기 (Wilk 외 2021). 단, 초 단위 값은 초깃값입니다.
- 정면: 중간 스탠스(어깨너비 100–150%), 무릎이 안쪽으로 모이지 않게 (Straub & Powers 2024). 좌우 대칭 기준은 초깃값입니다.

확인한 논문 목록과 앱에 반영한 내용은 [docs/참고문헌.md](docs/참고문헌.md)에 있습니다.
코드의 기준값에는 근거를 주석으로 달았습니다. `[논문 n]`은 논문 근거가 있는 값이고, `[초깃값]`은 아직 근거 없이 정한 값입니다.

## 실행

**배포된 주소**: GitHub Pages 주소를 폰 브라우저(크롬·사파리)로 엽니다. 카메라 촬영은 HTTPS에서만 되므로 Pages 주소로 여는 것이 가장 간단합니다.

**내 컴퓨터에서**:

```bash
python3 -m http.server 8640
```

`http://localhost:8640` 을 엽니다. ES 모듈을 쓰므로 파일을 더블클릭(`file://`)해서는 열리지 않습니다.
처음 한 번은 MediaPipe 모델(약 9MB)을 인터넷에서 받습니다.

**테스트**: `http://localhost:8640/tests/` 에서 합성 데이터로 분석 로직을 확인합니다.

## 실제 영상 확인 기록

| 영상 | 결과 |
|---|---|
| 맨몸 스쿼트, 측면 | 반복 6회 일치, 인식률 100% |
| 맨몸 스쿼트, 정면 | 반복 2회 일치, 좌우 균형 양호 |
| 바벨 스쿼트, 뒤에서 촬영(10회) | 반복 10회 일치, 좌우를 맞게 인식. 깊게 앉을 때 무릎 모임 오탐 → 수정 |
| 바벨 데드리프트, 대각선 앞 촬영(1회) | 1회 인식. 마무리 뒤 관절점이 엉켜 엉덩이 각도 360°대 → 불가능한 자세 프레임 버리도록 수정. 대각선 촬영이라 '뒤로 젖힘'이 나와 → 측면이 아닌 영상은 경고를 참고로 낮추고 '옆에서 다시 찍기'를 먼저 안내하도록 수정 |

| 데드리프트 설명 영상, 여러 장면을 이어 붙인 편집본(34초) | 측면 장면 2개가 서로 반대 방향이라 앞 장면이 통째로 버려짐 → 프레임마다 방향을 정하도록 수정. 장면 전환(사람이 사라짐, 방향 바뀜, 화면이 갑자기 바뀜)에 걸친 반복은 잘린 반복으로 처리하고 '편집된 영상' 경고. 판정 정답은 영상만으로 확인할 수 없어 미검증 |
| 데드리프트 측면(3회) + 정면(5회), 서로 다른 영상을 '둘 다'로 한 번에 올림 | 측면·정면 자동 구분 성공, 반복 수·리듬이 다르다는 경고 정상. 측면은 원판이 정강이·발을 가려 무릎 각도가 순간적으로 59°까지 튀고 뒤꿈치 들림이 오탐 → 데드리프트는 바닥 근처 무릎 각도를 중앙값으로 재고, 발바닥 접지 표시를 숨김. 마무리 −10~−11°가 '뒤로 젖힘'에 걸려 기준을 −15°로 넓힘. 정면 문구 '앉으세요' → '당기세요'. 정면: 컨벤셔널(어깨 대비 88%), 무릎 정렬·좌우 균형 양호 |
테스트 영상은 공개 영상으로 기기에서만 분석했고, 앱·저장소에는 넣지 않았습니다.

## 알려진 한계

- **각도 정의**: 앱의 각도는 2D 영상의 분절 기울기로 계산한 값이라, 논문에서 쓰는 국제생체역학회(ISB) 3D 관절 각도와 정의가 다릅니다(Wu 외 2002). 논문 수치와 직접 비교할 때 주의하세요.
- **카메라 측정 정확도**: 이 앱이 쓰는 MediaPipe로 스쿼트 무릎 각도를 잰 연구에서, 인식 품질이 좋은 프레임만 쓰면 일치도가 보통 수준(ICC 0.77)이었고, 걸러내지 않으면 크게 떨어졌습니다(Yue 외 2026). 앱은 신뢰도가 낮은 관절을 버리고 인식률이 낮으면 경고하지만, 결과는 선별용 참고값입니다.
- **정면 무릎 모임은 참고로만 표시합니다.** 2D 정면 무릎 측정은 실제 3D 움직임과 상관이 낮다는 연구가 있습니다(Haberkamp 외 2022).
- **측면 2D 각도도 3D보다 엉덩이·허벅지 각도가 3–13° 작게 나올 수 있습니다**(Escamilla 외 2001). 그래서 깊이 판정에 15° 여유를 두고, '둘 다' 모드의 3D 합성을 제공합니다.

- 기준값은 대부분 **초깃값**입니다(뒤꿈치 들림 3%, 무릎 안쪽 이동 4%, 상체 옆 기울기 5° 등). 실제로 틀린 자세를 찍은 영상으로 아직 보정하지 않았습니다.
- 등 곡률은 실험 기능입니다. 헐렁한 옷을 입으면 부정확합니다.
- 근육 부하는 관절 각도로 계산한 상대 추정치이며, 근전도(EMG)로 잰 값이 아닙니다.
- 체중 분배는 관절 위치로 추정한 값이며, 실제 발바닥 압력이 아닙니다.
- 정면 분석은 뒤에서 찍어도 좌우를 맞게 잡았어요(실제 영상 1개로 확인). 다만 깊게 앉아 무릎이 엉덩이 높이까지 오는 구간은 무릎 정렬을 재지 않고 앞뒤 프레임 값으로 채웁니다.
- 3D 합성은 측면에서 보이는 한쪽 다리의 앞뒤 위치를 양쪽 다리에 같이 씁니다.
- 등 윤곽(실험)은 사람 윤곽 마스크에서 재는데, 바벨 원판이 몸과 함께 잡힙니다. 위쪽 등 가장자리가 몸통 길이의 0.32배보다 멀어진 장면(사람 등으로는 불가능한 거리, 실제 영상 원판 0.38–0.42 vs 맨몸 0.22–0.25)이 30%를 넘으면 그 영상에서는 등 윤곽을 쓰지 않고 알려 줍니다(초깃값).
- 2D 영상이라 카메라 각도가 비뚤어지면 결과가 달라집니다. 측면은 정확히 옆에서, 정면은 정확히 앞에서 찍어 주세요.
