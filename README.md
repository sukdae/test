# 폼 체크 — 스쿼트 자세 분석 (웹 프로토타입)

폰으로 스쿼트 영상을 찍거나 불러오면 관절 위치를 인식해서 자세 피드백을 주는 웹앱입니다.
**영상은 브라우저 안에서만 처리**되고 어떤 서버로도 보내지 않습니다. 설치하지 않아도 폰 브라우저로 열면 됩니다.

> 시험 버전입니다. 의료 진단이 아니라 참고용 피드백입니다.

## 할 수 있는 것

- **촬영 방향 선택**: 측면, 정면, 둘 다 중에서 고릅니다. '둘 다'에서는 영상 두 개를 한 번에 올리면 측면·정면을 자동으로 구분합니다.
- **이렇게 해 보세요**: 결과 맨 위에 고칠 점을 행동 문장으로 최대 3개 보여 줍니다. 잘한 점은 칩으로 표시합니다.
- **영상 위 표시**: 관절 선, 기준 자세 고스트, 쓰이는 근육, 발바닥 접지(뒤꿈치 들림), 등 라인을 그립니다.
- **측면 분석**:
  - 깊이(허벅지 수평 각도)
  - 상체·정강이 각도, 엉덩이가 먼저 올라오는지
  - 뒤꿈치 들림
  - 하강·상승 속도
  - 상체 흔들림, 등 곡률(실험)
- **정면 분석**:
  - 무릎이 안쪽으로 모이는지, 골반 기울기, 엉덩이 쏠림
  - 스탠스 너비, 상체 옆 기울기
  - 좌우 체중 분배(추정), 한쪽 발이 뜨는지
  - 좌우 근육 사용
- **정면 기준 자세**: 정면에도 논문 기반 기준 자세(중간 스탠스, 무릎이 안쪽으로 모이지 않음, 좌우 대칭)를 점선으로 겹쳐 보고 '나 vs 기준' 표로 비교합니다.
- **3D 합성 (둘 다 모드, 추정)**: 측면(앞뒤·높이)과 정면(좌우)을 반복 위상으로 맞춰 3D 대표 동작을 만들고, 돌려 볼 수 있는 뼈대와 진단표를 보여 주고, 문제가 있는 반복이 몇 회째인지 표시합니다. 무릎 방향 vs 발끝 방향, 3D 무릎 각도, 상체 기울기(앞·옆)를 다룹니다. 두 영상이 같은 순간이 아니라서 근사값입니다.
- **두 영상 일치 확인**: 측면과 정면이 같은 세트가 아닌 것 같으면 경고합니다.
- **이미지로 공유**: '이렇게 해 보세요', 자세 장면, 3D 회차 표시를 이미지 한 장으로 만들어 카톡 등으로 보냅니다. 기본은 뼈대만 들어가고, '실제 영상 포함'을 켜야 영상 장면이 들어갑니다.
- **데드리프트 (베타)**: 측면만 분석합니다. 기준값은 논문 근거 없이 정한 초깃값이라 트레이너 피드백으로 맞출 예정입니다.
- **기록**: 세트별 결과를 기기 안(IndexedDB)에 저장하고 추이 그래프로 보여 줍니다. 영상 저장은 기본으로 꺼져 있습니다.

## 기준 자세와 근거

비교 기준은 특정 사람의 영상이 아니라 **논문을 근거로 만든 기준 자세**입니다.

- 깊이: 허벅지가 바닥과 평행 (Escamilla 2001)
- 상체와 정강이 기울기가 비슷하게 (Straub & Powers 2024)
- 천천히 내려가고 빠르게 올라오기 (Wilk 외 2021). 단, 초 단위 값은 초깃값입니다.
- 정면: 중간 스탠스(어깨너비 100–150%), 무릎이 안쪽으로 모이지 않게 (Straub & Powers 2024). 좌우 대칭 기준은 초깃값입니다.

확인한 논문 목록과 앱에 반영한 내용은 [docs/참고문헌.md](docs/참고문헌.md)에 있습니다.
코드의 기준값에는 근거를 주석으로 달았습니다. `[논문 n]`은 논문 근거가 있는 값이고, `[초깃값]`은 아직 근거 없이 정한 값입니다.

## 실행

**배포된 주소**: GitHub Pages 주소를 폰 브라우저(크롬·사파리)로 엽니다. 카메라 촬영은 HTTPS에서만 되므로 Pages 주소로 여는 것이 가장 간단합니다.

**내 컴퓨터에서**:

```bash
python3 -m http.server 8640
```

`http://localhost:8640` 을 엽니다. ES 모듈을 쓰므로 파일을 더블클릭(`file://`)해서는 열리지 않습니다.
처음 한 번은 MediaPipe 모델(약 9MB)을 인터넷에서 받습니다.

**테스트**: `http://localhost:8640/tests/` 에서 합성 데이터로 분석 로직을 확인합니다.

## 구조

```
index.html, styles.css   모든 화면
src/app.js               화면 전환
src/core/                분석 로직 (DOM 없음, 네이티브 앱으로 옮길 부분)
  analyze.js  측면 분석      front.js   정면 분석
  feedback.js 규칙·기준값    coach.js   '이렇게 해 보세요' 문장
  exercises.js 기준 자세     muscles.js 근육 부하 추정
  fuse3d.js 측면+정면 3D 합성  back.js 등 곡률(실험)
  reps.js / compare.js / signal.js / geometry.js ...
src/ui/                  브라우저 전용 (카메라, MediaPipe, 그리기, 저장)
tests/                   분석 로직 테스트
docs/                    참고문헌, 트레이너 피드백 요청서
```

## 알려진 한계

- 기준값은 대부분 **초깃값**입니다(뒤꿈치 들림 3%, 무릎 안쪽 이동 4%, 상체 옆 기울기 5° 등). 실제로 틀린 자세를 찍은 영상으로 아직 보정하지 않았습니다.
- 등 곡률은 실험 기능입니다. 헐렁한 옷을 입으면 부정확합니다.
- 근육 부하는 관절 각도로 계산한 상대 추정치이며, 근전도(EMG)로 잰 값이 아닙니다.
- 체중 분배는 관절 위치로 추정한 값이며, 실제 발바닥 압력이 아닙니다.
- 정면 분석은 뒤에서 찍어도 좌우를 맞게 잡았어요(실제 영상 1개로 확인). 다만 깊게 앉아 무릎이 엉덩이 높이까지 오는 구간은 무릎 정렬을 재지 않고 앞뒤 프레임 값으로 채웁니다.
- 3D 합성은 측면에서 보이는 한쪽 다리의 앞뒤 위치를 양쪽 다리에 같이 씁니다.
- 2D 영상이라 카메라 각도가 비뚤어지면 결과가 달라집니다. 측면은 정확히 옆에서, 정면은 정확히 앞에서 찍어 주세요.

## 앞으로

1. **PWA**: 홈 화면에 추가할 수 있게 합니다(manifest는 이미 들어 있음).
2. **Capacitor**: 지금 웹앱을 감싸서 앱스토어에 올립니다.
3. **네이티브 재작성**: 성능이 필요해지면 `src/core/`를 그대로 옮기고, `src/ui/pose.js`만 플랫폼용 MediaPipe SDK로 바꿉니다.
